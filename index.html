Bricklage

Property Purchase,Financing and verification platform

Project Overview

Bricklage is a web platform that allows users to browse, verify, and purchase properties such as land and houses. It also provides access to loan options for users who cannot pay outright.

Target Users: Property buyers and real estate investors

Problem Statement

Buyers juggle unverified listings and disconnected financing. Sellers can't find serious buyers, and lenders waste time on unqualified leads. The core problem is a lack of a secure, integrated platform that verifies authenticity and connects every piece of the transaction seamlessly.

Solution

Design a platform that:

  • Allows users to browse verified properties
  • Enables property verification requests
  • Provides loan application options
  • Offers a simple and transparent payment process
  • Role-Based Access: The platform supports different user roles;buyers, sellers, and financiers; each with tailored access and functionality. This ensures users only see information relevant to their goals while reducing unnecessary complexity.

Design Decisions

  • A clean layout and visual hierarchy were used to reduce cognitive overload.
  • Clear card layout for property listings
  • Simple form structure for verification
  • user-friendly Interface

Outcome

The design provides a secure and user-friendly way for buyers to explore properties, verify them, and proceed with confidence. Users can now make informed decisions with transparent information and multiple payment options.

Zappfix

Property Purchase,Financing and verification platform

Project Overview

Zappfix is a service marketplace that connects customers with skilled technicians such as electricians, plumbers, and repair specialists. It also allows technicians to create profiles and receive job requests.

Target Users: Customers needing repairs and technicians offering services

Problem Statement

Finding reliable technicians is difficult and risky. Customers often rely on word-of-mouth without guarantees. Technicians also struggle to find steady work opportunities.

Solution

Design a platform that:

  • Allows customers to search for technicians
  • Enables technician profile creation
  • Supports job booking and requests
  • Provides transparent service listings
  • Supports communication between users and technicians, reducing delays and misunderstandings.
  • Supports dispute resolution, reinforcing trust and platform reliability.

Design Decisions

  • Clean card-based layout for technicians
  • Simple booking process
  • Emphasis on profile trust elements
  • Clear navigation for both user types

Outcome

Zappfix simplifies how customers find skilled workers and helps technicians get more jobs through a digital platform. The design creates trust between both parties and streamlines the entire hiring process.
